# Create API Key

To use Pimlico's services, you'll need an API key. We recommend using our CLI for the quickest setup, but you can also use the dashboard.

## Using the CLI (Recommended)

Run the following command from your project's root directory:

```bash
npx @pimlico/cli init
```

Or, if you have the [Pimlico CLI](/references/platform/cli) installed globally:

```bash
pimlico init
```

This command will:
- Open your browser to log in the first time (the same account as the dashboard)
- Create a new API key
- Write it to your `.env` file as `PIMLICO_API_KEY`

The key is printed redacted in the terminal; the full key is only written to the file.

## Using the Dashboard

Alternatively, you can create an API key through our web dashboard:

1. Go to the [Pimlico Dashboard](https://dashboard.pimlico.io/)
2. Sign up or log in to your account
3. Click **API Keys** in the sidebar
4. Click **Create API key**
5. Copy your API key and add it to your project's `.env` file

:::warning
API keys are shown once, at creation. If you lose a key, create a new one, update your app, then disable the old one. See [API keys and handles](/references/platform/cli/api-keys).
:::

## Next Steps

Once you have your API key:
- Add it to your `.env` file as `PIMLICO_API_KEY=your_key_here`
- Start building with our [tutorials](/guides/tutorials/)
