# How to sponsor your users' transaction fees on any EVM chain

This guide shows you how to pay your users' transaction fees on Ethereum, Base, Arbitrum, Optimism, Polygon, BNB Chain, Avalanche or any other [supported EVM chain](/guides/supported-chains), so they can transact without holding the chain's native token. You send each user's transactions as an ERC-4337 user operation, and Pimlico's **verifying paymaster** pays the gas from your Pimlico balance. The code is the same on every chain: only the chain import changes. For Solana, see [Solana gas sponsorship](/guides/how-to/solana/verifying-sponsorship).

## Prerequisites

- A Pimlico API key. Sponsoring on mainnets needs a paid plan with a balance or card attached; testnets are free. [Create one](/guides/create-api-key).

::::code-group

```bash [npm]
npm install permissionless viem
```

```bash [pnpm]
pnpm install permissionless viem
```

```bash [bun]
bun install permissionless viem
```

::::

## Steps

::::steps

### Pick your chain

Import your chain from `viem/chains` as `chain`. The Pimlico URL in the next step is built from `chain.id`, so nothing else changes.



```ts [Polygon]
import { polygon as chain } from "viem/chains" // chain ID 137
```

## Sponsor an existing EOA with EIP-7702

To sponsor gas for a user's existing EOA without moving their funds, replace `toSimpleSmartAccount` with `to7702SimpleSmartAccount`, use EntryPoint 0.8, and attach a signed authorization to the user's first user operation. Follow the [EIP-7702 quickstart](/guides/eip7702/demo). Check the chain has EIP-7702 support on the [supported chains page](/guides/supported-chains#chain-details); Ethereum, Base, Arbitrum, Optimism and Polygon do.

## Test on a testnet first

To test without spending real funds, import a testnet such as `sepolia` or `baseSepolia` as `chain`. Sponsorship on testnets is free.

## Let users pay gas in USDC instead

To charge users instead of sponsoring them, have them pay gas in USDC with the ERC-20 Paymaster. Follow [How to send USDC without ETH for gas](/guides/how-to/payments/send-usdc-without-eth), and check your chain's USDC is listed in the [supported tokens](/references/paymaster/erc20-paymaster/supported-tokens).

## Limit what you sponsor (optional)

To cap your spend, for example per user or per user operation, create a policy in the [sponsorship policies dashboard](https://dashboard.pimlico.io/sponsorship-policies) and pass its ID in the `paymasterContext`. User operations outside the policy's limits are declined, and `sendUserOperation` throws.
