# How to sponsor transaction fees for users on Ethereum

This guide shows you how to pay your users' transaction fees on Ethereum mainnet, so they can transact without holding ETH. You send each user's transactions as an ERC-4337 user operation, and Pimlico's **verifying paymaster** pays the gas from your Pimlico balance.

## Prerequisites

- A Pimlico API key on a plan that includes mainnets, with a balance or card attached to cover sponsored gas. [Create one](/guides/create-api-key).

::::code-group

```bash [npm]
npm install permissionless viem
```

```bash [pnpm]
pnpm install permissionless viem
```

```bash [bun]
bun install permissionless viem
```

::::

## Sponsor an existing EOA with EIP-7702

Ethereum supports EIP-7702. To sponsor gas for a user's existing EOA without moving their funds, replace `toSimpleSmartAccount` with `to7702SimpleSmartAccount`, use EntryPoint 0.8, and attach a signed authorization to the user's first user operation. Follow the [EIP-7702 quickstart](/guides/eip7702/demo) and set the chain to `mainnet`.

## Test on Sepolia first

To test without spending real ETH, replace `mainnet` with `sepolia` from `viem/chains` and use chain ID `11155111` in the Pimlico URL. Sponsorship on testnets is free.

## Let users pay gas in USDC instead

To charge users instead of sponsoring them, pay gas in USDC (`0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48`) with the ERC-20 Paymaster. Follow [How to send USDC without ETH for gas](/guides/how-to/payments/send-usdc-without-eth) and change the chain to `mainnet`.

## Sponsor on other chains

The same code works on every [supported chain](/guides/supported-chains). Change the viem chain, the chain ID in the Pimlico URL and the RPC URL.

## Limit what you sponsor (optional)

To cap your spend, for example per user or per user operation, create a policy in the [sponsorship policies dashboard](https://dashboard.pimlico.io/sponsorship-policies) and pass its ID in the `paymasterContext`. User operations outside the policy's limits are declined, and `sendUserOperation` throws.
