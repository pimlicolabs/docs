# How to take the gas fee for a swap out of the token being swapped

This guide shows you how to offer gasless swaps where the network fee comes out of the token the user is selling, so a user who enters "spend 100 USDC" spends 100 USDC in total, gas included. You estimate the fee with Pimlico's **ERC-20 Paymaster**, quote the swap for the amount left after the fee, and send the approve and the swap as one user operation. If you only need swaps without ETH and the fee can sit on top of the amount, see [How to let users swap on Base without ETH](/guides/how-to/payments/swap-without-eth) instead.

## Prerequisites

- A Pimlico API key on a plan that includes mainnets. [Create one](/guides/create-api-key).
- A DEX aggregator or router API that returns swap calldata for a given sell amount and taker address.

## If the sell token can't pay gas

If `getTokenQuotes` returns no quote for the token, leave the `token` out of the `paymasterContext` and sponsor the swap from your Pimlico balance, as in [Sponsor the swap instead](/guides/how-to/payments/swap-without-eth#sponsor-the-swap-instead). To recover the cost, take your own fee in the swap itself if your aggregator supports an integrator fee.

## Let the user sell their whole balance

To build a "max" button, set the spend amount to the user's full balance. Keep the buffer from the fee step: without it, a small rise in gas price leaves too little to pay the fee and the user operation fails simulation.
