# How to bridge USDC between chains with Fast Bridge

This guide shows you how to move a user's USDC from one chain to another with Pimlico Fast Bridge, either to a recipient or straight into calls on the destination chain. The user signs one token authorization and holds no gas on either chain. For the supported routes, limits and how a request runs, see the [Fast Bridge overview](/references/fast-bridge).

This guide bridges native USDC from Base to Arbitrum with an EIP-3009 authorization. For BSC, which only takes Permit2, see [Bridge from a token without EIP-3009](#bridge-from-a-token-without-eip-3009).

## Prerequisites

- A Pimlico API key. [Create one](/guides/create-api-key).
- An EOA holding USDC on the origin chain, within the [per-request limit](/references/fast-bridge#supported-chains-and-tokens).

## Run calls on the destination chain

To use the bridged USDC in the same request, for example to deposit it into a vault, send `calls` instead of `recipient`. The bridge delivers `amountOut` to `multicaller` from `/addresses`, which then runs your calls in order as `msg.sender`, so approve and spend from `multicaller` and send any output to the user.

```ts
// [!include ~/snippets/payments/fast-bridge.ts:calls]
```

If a call would revert, the request is rejected with `CALLS_SIMULATION_REVERTED` before any funds move. If you already know the gas your calls need, pass it as `gasLimit` to skip the estimate.

:::warning
Make your calls spend or forward the full `amountOut`. The bridge doesn't return anything left on `multicaller` after your calls run.
:::

## Bridge from a token without EIP-3009

If the origin token only supports Permit2, such as Binance-Peg USDC on BSC, have the user approve the [Permit2 contract](https://github.com/Uniswap/permit2) (`0x000000000022D473030F116dDEE9F6B43aC78BA3`) for the token once, then sign a Permit2 `PermitTransferFrom` with `spender` set to the bridge's `approvalAddress`. Send it as a `permit2` authorization in the same request body.

```ts
// [!include ~/snippets/payments/fast-bridge.ts:permit2]
```

Without the Permit2 approval, the request is rejected with `INSUFFICIENT_ALLOWANCE`. Base, Arbitrum and Robinhood Chain take both authorization types.
