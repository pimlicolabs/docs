# How to send USDC remittances without ETH for gas

This guide shows you how to let remittance app users send USDC across borders without holding ETH: your app sponsors the network fee through the **verifying paymaster**, and if sponsorship is declined the user pays it in USDC through the **ERC-20 Paymaster**. If your users keep USDC in an EOA, also follow [Send from an existing EOA with EIP-7702](#send-from-an-existing-eoa-with-eip-7702).

This guide uses Base and its native USDC (`0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`). The same code works on any [supported chain](/guides/supported-chains): change the chain, the RPC URL and the USDC address, and check the [ERC-20 Paymaster's supported tokens](/references/paymaster/erc20-paymaster/supported-tokens).

Send the transfer without a `paymasterContext` so the verifying paymaster sponsors it from your Pimlico balance. If sponsorship is declined, the request fails: catch it and resend with `paymasterContext: { token: USDC }` so the ERC-20 Paymaster takes the fee from the user's USDC.

## Limit sponsored transfers per user (optional)

In the [dashboard](https://dashboard.pimlico.io/sponsorship-policies), create a policy for Base with a per-user daily limit, for example 5 user operations, and copy its ID (`sp_…`). ## Notes

- **Funding sponsorship**: keep your Pimlico balance (or attached card) able to cover the maximum cost of every sponsored user operation in flight. Pimlico holds each one's maximum possible cost and refunds the difference after it lands ([verifying paymaster FAQ](/references/paymaster/verifying-paymaster/faqs)).
- **Sponsorship validity**: if users may sign and submit later than 10 minutes after sponsorship, extend it with `validForSeconds` ([guide](/guides/how-to/paymasters/extending-sponsorship-duration)). ERC-20 Paymaster sponsorships are always valid for 10 minutes, so send fallback transfers in the same session.
- **Fiat and cross-chain**: to convert fiat to and from stablecoins or move funds between chains, use an on/off-ramp or bridge provider. Pimlico only covers gas and transaction inclusion.
