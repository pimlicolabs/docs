# How to send USDC remittances without ETH for gas

This guide shows you how to let remittance app users send USDC across borders without holding ETH: your app sponsors the network fee through the **verifying paymaster** under a **sponsorship policy** that caps your spend, and falls back to the user paying it in USDC through the **ERC-20 Paymaster**. If your users keep USDC in an EOA, also follow [Send from an existing EOA with EIP-7702](#send-from-an-existing-eoa-with-eip-7702). Converting fiat to and from stablecoins and moving funds between chains need an on/off-ramp or bridge provider; Pimlico only covers gas and transaction inclusion.

This guide uses Base and its native USDC (`0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`). The same code works on any [supported chain](/guides/supported-chains): change the chain, the RPC URL and the USDC address, and check the [ERC-20 Paymaster's supported tokens](/references/paymaster/erc20-paymaster/supported-tokens) if you use the fallback.

## Steps

::::steps

### Create a sponsorship policy

In the [dashboard](https://dashboard.pimlico.io/sponsorship-policies), create a policy for Base with a per-user daily limit, for example 5 user operations, and copy its ID (`sp_…`). Once a user reaches the limit, sponsorship fails and the transfer falls back to USDC. For more controls, such as sponsoring only your own customers, see [sponsorship policies](/guides/how-to/sponsorship-policies).

Create a public client, a Pimlico client (used as both bundler and paymaster), the user's smart account, and a smart account client.

## Running this in production

- **Funding sponsorship**: keep your Pimlico balance (or attached card) able to cover the maximum cost of every sponsored user operation in flight. Pimlico holds each one's maximum possible cost and refunds the difference after it lands ([verifying paymaster FAQ](/references/paymaster/verifying-paymaster/faqs)).
- **Sponsorship validity**: a sponsorship signature is valid for 10 minutes by default. If users may sign and submit later, extend it with `validForSeconds` ([guide](/guides/how-to/paymasters/extending-sponsorship-duration)). ERC-20 Paymaster sponsorships are always valid for 10 minutes.
- **Several chains**: the clients and the code are the same on every chain Pimlico supports. Allow each chain in your policy.
