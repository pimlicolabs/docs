# Sponsor with USDC or other SPL tokens

This guide shows you how to let your users pay their Solana transaction fees in USDC or another SPL token instead of SOL.

The paymaster pays the SOL fee, and your user repays it with a token transfer in the same transaction. The `@pimlico/solana` SDK adds the token payment for you.

## Steps

::::steps
### Install the SDK

```sh
npm install @pimlico/solana @solana/kit
```

### Create the paymaster client

```ts
import { createSolanaPaymaster } from "@pimlico/solana";
import { createSolanaRpc } from "@solana/kit";

const solanaRpc = createSolanaRpc("https://api.mainnet-beta.solana.com");

const paymaster = createSolanaPaymaster({
    paymasterUrl: "https://solana.pimlico.io/v1/rpc?apikey=YOUR_API_KEY",
    solanaRpc,
});
```

### Pick a token

`getSupportedTokens` returns the tokens users can pay with. This guide uses USDC.

```ts
const { tokens } = await paymaster.rpc.getSupportedTokens();
const usdc = tokens.find((token) => token.symbol === "USDC")!;
```

### Build your instructions

This example sends 5 USDC to another wallet.

```ts
import {
    address,
    createKeyPairSignerFromBytes
} from "@solana/kit";
import {
    findAssociatedTokenPda,
    getTransferCheckedInstruction,
    TOKEN_PROGRAM_ADDRESS,
} from "@solana-program/token";

const user = await createKeyPairSignerFromBytes(USER_SECRET_KEY);
const recipient = address("RecipientPubkey11111111111111111111111111111");

const [source] = await findAssociatedTokenPda({
    owner: user.address,
    mint: usdc.mint,
    tokenProgram: TOKEN_PROGRAM_ADDRESS,
});
const [destination] = await findAssociatedTokenPda({
    owner: recipient,
    mint: usdc.mint,
    tokenProgram: TOKEN_PROGRAM_ADDRESS,
});

const instructions = [
    getTransferCheckedInstruction({
        source,
        mint: usdc.mint,
        destination,
        authority: user,
        amount: 5_000_000n, // 5 USDC
        decimals: usdc.decimals,
    }),
];
```

### Show the fee (optional)

Call `estimateFee` to show your user what the fee will cost before they confirm.

```ts
const estimate = await paymaster.estimateFee({
    instructions,
    mint: usdc.mint,
});

const fee = Number(estimate.feeInToken) / 10 ** usdc.decimals;
console.log(`Fee: ${fee} USDC (~$${estimate.usdValue.toFixed(4)})`);
```

### Send the sponsored transaction

Pass the instructions, your user's signer, and `sponsorship.type` set to `"token"` with the mint. The SDK gets the fee estimate, appends a USDC transfer to the paymaster's vault, signs, submits, and returns the transaction signature.

```ts
const signature = await paymaster.sendTransaction({
    instructions,
    signers: [user],
    sponsorship: { type: "token", mint: usdc.mint },
});

console.log(`https://solscan.io/tx/${signature}`);
```

The first signer pays. Their USDC account must exist and hold enough to cover the fee.

### Wait for the transaction to land

```ts
const status = await paymaster.waitForTransaction(signature);

if (status.status === "finalized" && status.sponsorship.type === "token") {
    console.log(`Paid ${status.sponsorship.amount} raw USDC ($${status.sponsorship.usdValue})`);
} else {
    console.error(status.status, status.failureReason);
}
```

## Using an external wallet

If your users sign with a wallet like Phantom, use `prepareTransaction` to build the unsigned transaction with the payment already added, let the wallet sign it, then submit it with `sponsorTransaction`.

```ts
const transaction = await paymaster.prepareTransaction({
    instructions,
    payer: walletAddress,
    sponsorship: { type: "token", mint: usdc.mint },
});

const signed = await wallet.signTransaction(transaction);

const { signature } = await paymaster.sponsorTransaction(signed, {
    type: "token",
    mint: usdc.mint,
});
```

The wallet will show both the user's instructions and the USDC payment to the vault.

## Errors

Errors specific to token payment:

- `-32004` `PAYMENT_INSUFFICIENT`: the payment is too small, usually because prices moved since the estimate. Send the transaction again.
- `-32006` `UNSUPPORTED_TOKEN`: the mint is not in `getSupportedTokens`.
- `-32008` `PRICE_UNAVAILABLE`: the price for the token is stale. Try again shortly.

```ts
import { SolanaPaymasterError } from "@pimlico/solana";

try {
    await paymaster.sendTransaction({ /* ... */ });
} catch (error) {
    if (
        error instanceof SolanaPaymasterError &&
        error.code === SolanaPaymasterError.codes.PAYMENT_INSUFFICIENT
    ) {
        // error.data has { required, provided, mint }
    }
}
```

See the [errors reference](/references/paymaster/solana/errors) for the full list.

:::warning
If the transaction fails on chain, the user's token payment fails with it, but the SOL fee is still paid. That fee is charged to your Pimlico balance. The paymaster simulates every transaction before sponsoring it, so this only happens when something changes between simulation and execution, such as a swap exceeding its slippage limit.
:::

## Good to know

- **Overpaying is accepted but not refunded.** The paymaster only checks the payment covers the fee.
- **Token account rent is covered too.** If your transaction creates a token account, set the paymaster as its rent payer. The rent is added to the fee the user pays.
- **The estimate is advisory.** Prices are re-checked when the transaction arrives. If they moved, you'll get `-32004` and should send again.
- **Retrying is safe.** Sending the same transaction twice won't broadcast it twice. See [retrying safely](/guides/how-to/solana/verifying-sponsorship#retrying-safely).

## Full example

```ts
import { createSolanaPaymaster } from "@pimlico/solana";
import {
    address,
    createKeyPairSignerFromBytes,
    createSolanaRpc
} from "@solana/kit";
import {
    findAssociatedTokenPda,
    getTransferCheckedInstruction,
    TOKEN_PROGRAM_ADDRESS,
} from "@solana-program/token";

const paymaster = createSolanaPaymaster({
    paymasterUrl: "https://solana.pimlico.io/v1/rpc?apikey=YOUR_API_KEY",
    solanaRpc: createSolanaRpc("https://api.mainnet-beta.solana.com"),
});

const user = await createKeyPairSignerFromBytes(USER_SECRET_KEY);
const recipient = address("RecipientPubkey11111111111111111111111111111");

const { tokens } = await paymaster.rpc.getSupportedTokens();
const usdc = tokens.find((token) => token.symbol === "USDC")!;

const [source] = await findAssociatedTokenPda({
    owner: user.address,
    mint: usdc.mint,
    tokenProgram: TOKEN_PROGRAM_ADDRESS,
});
const [destination] = await findAssociatedTokenPda({
    owner: recipient,
    mint: usdc.mint,
    tokenProgram: TOKEN_PROGRAM_ADDRESS,
});

const signature = await paymaster.sendTransaction({
    instructions: [
        getTransferCheckedInstruction({
            source,
            mint: usdc.mint,
            destination,
            authority: user,
            amount: 5_000_000n,
            decimals: usdc.decimals,
        }),
    ],
    signers: [user],
    sponsorship: { type: "token", mint: usdc.mint },
});

const status = await paymaster.waitForTransaction(signature);
console.log(signature, status.status, status.sponsorship);
```
