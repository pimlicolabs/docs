# Solana Sponsorships

Solana Sponsorships lets you sponsor the transaction fees for your users on Solana, so they can transact without holding SOL.

The paymaster speaks the [Kora](https://github.com/solana-foundation/kora) JSON-RPC API, so you use the `@solana/kora` SDK's `KoraClient` and build transactions with `@solana/kit`.

## Gas Sponsorships

You pay the fee for your users. It is charged to your Pimlico balance.

[Use Gas Sponsorships →](/guides/how-to/solana/verifying-sponsorship)

## SPL Token Sponsorships

Your users pay the fee in USDC or USDT ([supported tokens](/guides/how-to/solana/supported-tokens)). The paymaster pays the SOL fee and is repaid with a token transfer in the same transaction.

[Use SPL Token Sponsorships →](/guides/how-to/solana/token-sponsorship)

## Quick start

```sh
npm install @solana/kora @solana/kit @solana-program/token
```

Add a helper that builds a transaction message with the paymaster as the fee payer:

```ts [sponsored-transaction.ts]
import {
    type Address,
    type Blockhash,
    type Instruction,
    appendTransactionMessageInstructions,
    createNoopSigner,
    createTransactionMessage,
    pipe,
    setTransactionMessageFeePayerSigner,
    setTransactionMessageLifetimeUsingBlockhash,
} from "@solana/kit";

type SponsoredTransactionParams = {
    /** The paymaster's fee payer address. The paymaster signs for it later, so we use a noop signer here. */
    feePayer: Address;
    /** Transaction lifetime, from a recent blockhash. */
    lifetime: { blockhash: Blockhash; lastValidBlockHeight: bigint };
    /** Your app's instructions (transfers, swaps, etc.). */
    instructions: Instruction[];
};

export function createSponsoredTransactionMessage({
    feePayer,
    lifetime,
    instructions,
}: SponsoredTransactionParams) {
    return pipe(
        createTransactionMessage({ version: 0 }),
        (m) => setTransactionMessageFeePayerSigner(createNoopSigner(feePayer), m),
        (m) => setTransactionMessageLifetimeUsingBlockhash(lifetime, m),
        (m) => appendTransactionMessageInstructions(instructions, m),
    );
}
```

Then build your transaction with it and send it to the paymaster:

```ts
import { KoraClient } from "@solana/kora";
import {
    address,
    blockhash,
    getBase64EncodedWireTransaction,
    partiallySignTransactionMessageWithSigners,
} from "@solana/kit";
import { createSponsoredTransactionMessage } from "./sponsored-transaction";

const kora = new KoraClient({
    rpcUrl: "https://solana.pimlico.io/v1/mainnet/rpc?apikey=YOUR_API_KEY",
});

// The paymaster's fee payer
const { signer_address } = await kora.getPayerSigner();
const { blockhash: recentBlockhash } = await kora.getBlockhash();

const message = createSponsoredTransactionMessage({
    feePayer: address(signer_address),
    lifetime: { blockhash: blockhash(recentBlockhash), lastValidBlockHeight: 0n },
    instructions,
});

// Your user signs here, the paymaster signs as fee payer and broadcasts
const transaction = await partiallySignTransactionMessageWithSigners(message);

const { signature } = await kora.signAndSendTransaction({
    transaction: getBase64EncodedWireTransaction(transaction),
});
```

## How it works

1. You build your transaction with the paymaster's address, from `getPayerSigner`, as the fee payer, and your user signs it.
2. To have your user pay in a token, you append a transfer of the quoted fee to the paymaster before signing.
3. `signAndSendTransaction` sends it to the paymaster. If the transaction pays the paymaster in a supported token, the fee is covered by that payment. Otherwise it is charged to your Pimlico balance.
4. The paymaster validates and simulates the transaction, signs it as fee payer, broadcasts it, and by default responds once it is `confirmed`.

The signature is a normal Solana transaction signature, so you can look it up on any explorer.

:::info
`KoraClient` wraps a JSON-RPC API. If you'd rather call it directly, see the [endpoint reference](/references/paymaster/solana/endpoints).
:::

## Endpoints

| Cluster | URL |
|---|---|
| Mainnet | `https://solana.pimlico.io/v1/mainnet/rpc?apikey=YOUR_API_KEY` |
| Devnet | `https://solana.pimlico.io/v1/devnet/rpc?apikey=YOUR_API_KEY` |

Pass your API key in the `apikey` query parameter, as above. `KoraClient`'s own `apiKey` option sends an `x-api-key` header, which Pimlico does not read. Sponsorship on devnet is free.

## Requirements

- The paymaster may only be the fee payer, with one exception: it may pay the rent for an account your transaction creates, such as a token account. Any other use of it is rejected.
- The paymaster spends at most 0.1 SOL on one transaction, including the fee, priority fee, and rent.
- Every signer other than the paymaster must sign before you submit.
- One transaction per request.
