# How to pay gas fees for an AI agent's wallet

This guide shows you how to pay gas for an AI agent that sends transactions from its own wallet, without funding the agent with ETH. The agent gets a smart account, and Pimlico's **verifying paymaster** sponsors its gas from your Pimlico balance. If you'd rather the agent pay its own gas, see [Let the agent pay its own gas in USDC](#let-the-agent-pay-its-own-gas-in-usdc).

This guide uses Base. The same code works on any [supported chain](/guides/supported-chains) once you change the chain, the RPC URL and the USDC address.

## Prerequisites

- A Pimlico API key on a plan that includes mainnets. [Create one](/guides/create-api-key).
- A signer for the agent from a key management service or server wallet (Turnkey, Privy, Fireblocks, a cloud KMS) that you can load as a viem `LocalAccount`. See [signers](/guides/how-to/signers).



## Run many agents

Create one smart account per agent, each from its own signer. If one agent sends several transactions at once, give each its own nonce key, as described in [How to send multiple user operations in parallel](/guides/how-to/parallel-transactions).

## Use an agent's existing EOA

If the agent already has an EOA with funds in it, keep its address with EIP-7702: replace `toSafeSmartAccount` with `to7702SimpleSmartAccount` (EntryPoint 0.8) and attach a signed authorization to the first user operation. See the [EIP-7702 quickstart](/guides/eip7702/demo).

## Let a key you control recover the agent's funds

To recover funds or rotate the agent's key, add a key you control as a second owner of the Safe. See [How to create and use a Safe account with multiple signers](/guides/how-to/accounts/use-safe-account-with-multiple-signers).

## Limit what you sponsor (optional)

To cap how much gas an agent can spend, create a policy in the [sponsorship policies dashboard](https://dashboard.pimlico.io/sponsorship-policies) with a per-user limit (one "user" is one agent account) and pass its ID in the `paymasterContext`.
