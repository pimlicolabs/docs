# Fast Bridge

Fast Bridge lets your users move USDC across chains in seconds and use it straight away on the destination chain.

## How it works

Your user signs a single message to approve the transfer. Pimlico delivers the same amount on the destination chain in the next block, and covers the gas on both chains. Pimlico pays out instantly from its own liquidity, so there's no cross-chain message to wait for.

Fast Bridge is an HTTP API at `https://api.pimlico.io/v1/bridge` that uses your Pimlico API key.

## Supported chains

| Chain | Token |
|---|---|
| Base | USDC |
| Arbitrum | USDC |
| BSC | USDC |
| Robinhood | USDG |
| Solana | USDC |

Any chain can bridge to any other. See the [reference](/references/fast-bridge#supported-chains-and-tokens) for token addresses and limits.
