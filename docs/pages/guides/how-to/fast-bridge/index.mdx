# Fast Bridge

Fast Bridge moves your users' stablecoins from one chain to another in seconds. The user signs one authorization for the token on the origin chain, and Pimlico delivers the same amount from its own liquidity on the destination chain. Pimlico pays the gas on both chains, so the user needs no native token anywhere.

Fast Bridge is an HTTP API at `https://api.pimlico.io/v1/bridge` that uses your Pimlico API key.

## Bridge USDC to an address

Deliver the bridged USDC to the user, or to any recipient, on the destination chain.

## Run calls on the destination chain

Spend the bridged USDC in the same request, for example to deposit it into a vault or pay a merchant.

## Bridge from BSC

Binance-Peg USDC has no EIP-3009 support, so the user signs a Permit2 transfer instead.

[Bridge USDC from BSC with Permit2 →](/guides/how-to/fast-bridge/bridge-with-permit2)

## Supported chains

| Chain | Token | Authorizations |
|---|---|---|
| Base | USDC | `eip3009`, `permit2` |
| Arbitrum | USDC (native) | `eip3009`, `permit2` |
| BSC | USDC (Binance-Peg) | `permit2` |
| Robinhood Chain | USDG | `eip3009`, `permit2` |
| Solana | USDC | `solana-transaction` |

Any route between two different chains in the table works, up to 1,000 tokens per request. For token addresses, decimals and limits, see [supported chains and tokens](/references/fast-bridge#supported-chains-and-tokens).
