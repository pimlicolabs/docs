# How to bridge to a recipient

This guide shows you how to bridge USDC to a recipient on the destination chain with Fast Bridge. To call contracts with it on the destination chain instead, see [How to bridge and call contracts](/guides/how-to/fast-bridge/bridge-and-call).

## Prerequisites

- A Pimlico API key with Fast Bridge enabled.
- An account holding USDC on the origin chain.

::::code-group

```bash [npm]
npm install viem
```

```bash [pnpm]
pnpm install viem
```

```bash [bun]
bun install viem
```

::::

### Check the result

Read `status` from the response:

- `success`: the USDC was delivered in `destination.transactionHash`.
- `failed`: nothing was bridged, and the USDC is still on the origin chain.
- `pending`: the bridge hasn't finished. See [How to check a bridge's status](/guides/how-to/fast-bridge/track-request).
