# How to bridge tokens between chains with Fast Bridge

This guide shows you how to move a user's tokens from one chain to another with Pimlico Fast Bridge. The user signs one token authorization and holds no gas on either chain. To spend the tokens on the destination chain in the same request, see [How to bridge tokens and call contracts on the destination chain](/guides/how-to/fast-bridge/bridge-and-call).

## Prerequisites

- A Pimlico API key. [Create one](/guides/create-api-key).
- An EOA holding a [supported token](/references/fast-bridge#supported-chains-and-tokens) on the origin chain, within the per-request limit. The steps use USDC on Base.

### Sign a ReceiveWithAuthorization

Have the user sign an EIP-3009 `ReceiveWithAuthorization` for the amount to bridge, with `to` set to `approvalAddress` and a random 32-byte nonce. Give it a `validBefore` a few minutes ahead: the origin pull must land before it. If the origin token has no EIP-3009 support, sign a Permit2 transfer instead, as in [Bridge from BSC](#bridge-from-bsc).

## Bridge from BSC

Binance-Peg USDC on BSC has no EIP-3009 support, so have the user sign a [Permit2](https://github.com/Uniswap/permit2) `PermitTransferFrom` with `spender` set to `approvalAddress`, and send it as a `permit2` authorization. The token has 18 decimals, so parse the amount with 18.

The user must first approve the Permit2 contract (`0x000000000022D473030F116dDEE9F6B43aC78BA3`) for the token, once, in a transaction paid in BNB. Without it, the request is rejected with `INSUFFICIENT_ALLOWANCE`.
