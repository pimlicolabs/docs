# How to bridge to and from Solana

This guide shows you how to bridge USDC to and from Solana with Fast Bridge. The steps bridge from Solana to an EVM chain, and [Bridge to Solana](#bridge-to-solana) covers the other direction.

## Prerequisites

- A Pimlico API key with Fast Bridge enabled.
- A Solana account holding USDC.

::::code-group

```bash [npm]
npm install @solana/kit @solana-program/token
```

```bash [pnpm]
pnpm install @solana/kit @solana-program/token
```

```bash [bun]
bun install @solana/kit @solana-program/token
```

::::

### Send the request

Send the signed transaction as a `solana-transaction` authorization, with the origin and destination chains, the tokens and an EVM `recipient`. Send it within about a minute, before the transaction's blockhash expires. `bridgeTokens` returns once the bridge has finished, and throws if the request is rejected. ### Check the result

Read `status` from the response:

- `success`: the USDC was delivered in `destination.transactionHash`.
- `failed`: nothing was bridged, and the USDC is still on Solana.
