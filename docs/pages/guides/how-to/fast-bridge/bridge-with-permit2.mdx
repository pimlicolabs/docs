# How to bridge from BSC

This guide shows you how to bridge USDC from BSC with Fast Bridge. USDC on BSC has no EIP-3009 support, so you sign a Permit2 transfer instead. To bridge from another EVM chain, see [How to bridge to a recipient](/guides/how-to/fast-bridge/bridge-tokens) instead.

## Prerequisites

- A Pimlico API key with Fast Bridge enabled.
- An account holding USDC on BSC, and enough BNB for one approval.

::::code-group

```bash [npm]
npm install viem
```

```bash [pnpm]
pnpm install viem
```

```bash [bun]
bun install viem
```

### Check the result

Read `status` from the response:

- `success`: the USDC was delivered in `destination.transactionHash`.
- `failed`: nothing was bridged, and the USDC is still on the origin chain.
