# How to bridge USDC from BSC with Permit2

This guide shows you how to bridge USDC from a token that has no EIP-3009 support, such as Binance-Peg USDC on BSC, with Pimlico Fast Bridge. The user signs a [Permit2](https://github.com/Uniswap/permit2) transfer instead of a `ReceiveWithAuthorization`. On Base, Arbitrum and Robinhood Chain, [EIP-3009](/guides/how-to/fast-bridge/bridge-usdc) needs no approval, so use it there.

## Prerequisites

- A Pimlico API key. [Create one](/guides/create-api-key).
- An EOA holding Binance-Peg USDC on BSC, within the [per-request limit](/references/fast-bridge#supported-chains-and-tokens).
- An approval from that EOA to the Permit2 contract (`0x000000000022D473030F116dDEE9F6B43aC78BA3`) for the token. It's a one-time transaction, paid in BNB. Without it, the request is rejected with `INSUFFICIENT_ALLOWANCE`.
