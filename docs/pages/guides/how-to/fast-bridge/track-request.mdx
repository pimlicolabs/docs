# How to check a bridge's status

This guide shows you how to follow a Fast Bridge request until it finishes. Use it when a response comes back `pending`, or when you [start a request without waiting](#start-a-request-without-waiting) for it.

## Prerequisites

- A Pimlico API key with Fast Bridge enabled.
- The response of a bridge request, from one of the other [Fast Bridge guides](/guides/how-to/fast-bridge).

### Check the outcome

Read `status` from the result:

- `success`: the USDC was delivered in `destination.transactionHash`.
- `failed`: nothing was bridged, and the USDC is still on the origin chain.
- `pending`: the delivery failed, and `destination.error` says why. See [leg errors](/references/fast-bridge/errors#destination-leg).
