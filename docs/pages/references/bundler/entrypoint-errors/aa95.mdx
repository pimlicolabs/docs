# AA95 out of gas

`AA95 out of gas` is an ERC-4337 EntryPoint error that means the bundler sent the `handleOps` transaction with too low a gas limit for the user operations in it.

The bundler tried to bundle the user operation with the gas limit set too low.

## Possible solutions

- If you are using a bundler provider like Pimlico, [reach out to them](https://t.me/pimlicoHQ).
